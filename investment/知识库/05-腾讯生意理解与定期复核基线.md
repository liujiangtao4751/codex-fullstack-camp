# 腾讯：生意理解与定期复核基线

建立日期：2026-10-01；更新日期：2026-10-04；v0.4。  
用途：家庭投资体系首个战略研究样本。先看营收和利润，有疑点再解释现金及会计差异。  
给用户的短版：[腾讯2026年二季度经营复核](09-腾讯经营复核-2026年二季度.md)。

## 1. 当前研究判断

**单季和多年事实均支持腾讯仍有收入增长和盈利能力；报表利润受投资相关会计影响，大额现金投入是需要继续观察的实质变化。** 五年营收与利润、滚动盈利和估值的初筛已汇总于[多年经营与估值初筛](11-腾讯多年经营与估值初筛.md)。这足以保留腾讯作为重点研究样本，但不足以证明未来十年表现、当前估值合适或完整资产健康。

腾讯已有用户的实际交易与认可。参考段永平是用户表达的选择来源；其本人公开自述与监控边界已按日期整理于[参考持有证据](10-段永平腾讯参考持有证据与监控边界.md)，不推定巴菲特持有腾讯。公司经营、参考者持有、当前价格是否合适，分别取证。

## 3. 生意规模与利润：先把口径对齐

腾讯主要收入分部为增值服务、营销服务、金融科技及企业服务，涉及游戏与内容、广告、支付及云等。我们关注的是这些服务能否持续让客户付钱，并留下利润与现金。[公告第6—7页](https://www1.hkexnews.hk/listedco/listconews/sehk/2026/0812/2026081200296.pdf)

以下金额均为**人民币亿元、单季**，原表为人民币百万元，除以100换算。“归母”指属于腾讯公司股东的利润。

| 指标 | 2025Q2 | 2026Q1 | 2026Q2 | Q2同比 | Q2环比 |
|---|---:|---:|---:|---:|---:|
| 营收 | 1,845.04 | 1,964.58 | 2,047.85 | +10.99% | +4.24% |
| 报表归母利润（IFRS） | 556.28 | 580.93 | 560.22 | +0.71% | −3.56% |
| 调整后归母利润（non-IFRS） | 630.52 | 679.05 | 684.15 | +8.51% | +0.75% |

来源：新闻稿第5页、公告第1页。增长率由原始金额复算；公司摘要将同比写为11%、0.7%、9%，精度不同，不是数据冲突。同比为2026Q2对2025Q2，环比为2026Q2对2026Q1；这三列不是连续三个季度。季节性可能影响环比，不能把它当成长期趋势。

**研究判断：**营收与两种利润均同比增长，支持本季规模扩大、仍有盈利。利润增速分化值得解释；这组比较不等于已经证明持续多年的增长。

## 4. 两种利润为什么相差123.93亿元

以下严格使用**归母利润行**，不混用全体净利润或联营利润行。正号表示由报表口径调向non-IFRS时加回，负号表示扣除；不是现金流入或流出。

| 2026Q2调整项 | 人民币亿元 |
|---|---:|
| 报表归母利润 | 560.22 |
| 股权激励 | +77.56 |
| 被投公司净损益相关调整 | +45.27 |
| 收购形成的无形资产摊销 | +26.11 |
| 减值转回相关调整 | −20.64 |
| 可持续社会价值、共同富裕项目及其他捐赠 | +8.61 |
| 其他调整 | +6.47 |
| 所得税影响 | −19.45 |
| **调整合计** | **+123.93** |
| **调整后归母利润** | **684.15** |

来源：新闻稿第9页、公告第14页。逐项求和已通过复算。上年同期调整合计74.24亿元，今年增加49.69亿元；调整后利润同比增加53.63亿元，报表利润只增加3.94亿元，两者增加额之差正是49.69亿元。这说明调整项的跨期变化影响了所见利润增速，并不单独解释每项调整的经济含义。

**公司对一项重要差异的解释：**某未上市被投企业估值上升，导致其发行的可赎回可转换优先股重估，形成腾讯确认的联营损失；公司在non-IFRS中剔除了该影响。[公告第8页](https://www1.hkexnews.hk/listedco/listconews/sehk/2026/0812/2026081200296.pdf)

**助手的理解：**这是“被投企业估值上升，也可能压低当期会计利润”的例子，不能把本期报表利润增长偏低全部解释成AI投入，或直接判为主营生意恶化。但上表还包含股权激励等其他项目，123.93亿元不能全部归到这一项。调整后利润也不是现金；股权激励可能带来股东稀释等经济成本，不因被加回就当作没有成本。

## 5. 现金投入：把真实支付与补充解释分开

公司披露的2026Q2现金摘要如下，金额为人民币亿元，保留摘要的舍入精度。

| 项目 | 金额 |
|---|---:|
| 经营活动产生的净现金 | 527 |
| 资本开支现金支付 | −593 |
| 媒体内容支付 | −50 |
| 租赁负债支付 | −22 |
| **自由现金流** | **−138** |

复算为527−593−50−22＝−138。公司说明经营现金流中已包含大额AI相关预付款；若剔除算力采购预付款，自由现金流为376亿元。[新闻稿第2页](https://www.tencent.com/wp-content/uploads/2026/08/Tencent-Announces-2026-Second-Quarter-Results.pdf)、[公告第17页](https://www1.hkexnews.hk/listedco/listconews/sehk/2026/0812/2026081200296.pdf)

预付款已在经营现金流中体现，不能再扣一次。376亿元是公司提供的补充视角，实际自由现金流仍是负138亿元。本季资本开支确认额527.84亿元与资本开支现金支付593亿元定义不同，不能互换。[公告第12页及第17页](https://www1.hkexnews.hk/listedco/listconews/sehk/2026/0812/2026081200296.pdf)

**研究判断：**现金先投入、回报以后出现是可能的路径，但本期披露尚不能证明未来回报。下一步要看投入能否对应收入、利润和现金回收；单季负值不足以断言生意恶化，管理层说明也不足以消除这个研究问题。

## 6. 留给下一次检查的三条依据

这是助手建立的初始观察依据，不是假称用户以前设过这些预期，也不是自动交易阈值。

| 依据 | 当前证据支持到哪一步 | 什么变化需要重新研究 |
|---|---|---|
| 主要服务仍能吸引付费，规模有扩张能力 | 本季营收同比增长10.99% | 同期收入转弱且不能由季节、汇率或明确业务变化解释；需追到具体业务 |
| 收入能转成股东利润 | 本季两种归母利润均为正且同比增长；差异已能对账 | 利润持续弱于收入，或投资调整无法解释分化；需查经营成本及盈利质量 |
| 投入有望转成后续回报 | 本季有大额预付款，公司说明投入用途；回报尚待验证 | 支出持续较高，但业务收入、利润和现金回收未见相应进展；先核实投入周期 |

这些变化先核实，再结合原持有理由形成“继续持有、继续核实、建议清仓”结论。若腾讯的指定参考投资者已确认减持，只将其纳入清仓操作判断，不改变用户自己的波段交易；若核实确认企业经营/投资逻辑实质恶化，应明确建议清仓。未找到持有更新不能写成“未减持”。所有建议均由人决定并手动执行。

## 7. 低时间投入的协作方式

助手先查证和解释，给用户留一页结论：当前支持什么、最重要的变化、还缺什么，以及继续持有、继续核实或建议清仓。财报披露后做同口径复核；月度轻查及重大事件检查属于拟采用的研究安排，尚未启动后台任务。

“资料不足”“未发现重大变化”和“已充分支持原判断”分开记录。首次研究只建立基线，不能声称验证了事先预测，也不把单次研究扩展成完整健康保证。
