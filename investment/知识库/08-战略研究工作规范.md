# 战略研究工作规范

日期：2026-10-01，v0.1。由助手负责执行，用户作关键判断。当前是项目内可直接使用的研究规范，未注册为自动加载的Skill或后台任务。

## 1. 分工与适用范围

用户已明确将财报计算、资料搜集与商业模式研究交由助手承担。助手核验事实、解释变化、给出有依据的研究判断与未知；用户决定是否认可、是否继续参与及如何操作。信息足够时助手先完成工作，不反复要求用户准备材料。

研究优先覆盖少量候选及已有资产。先把营收、利润讲清楚，需要解释时才扩展业务、现金、治理等项目。资产适合长期经营观察，不等于每份库存必须长期持有；现行交易规则以03文档及用户新解释为准。

## 2. 每项资产固定一个可更新的依据记录

记录资产名称、报告期间、查阅日期、选入理由和来源。选入理由可能来自用户实践、认可投资者的公开持有或助手提出的研究假设，分别标明。

只选少量真正影响判断的依据。为每条留下：支持事实、相反事实、目前解释、还缺什么、什么新事实会让我们重新判断。暂无证据时明确写暂无，不用模仿大师的口吻填空。

参考持仓另记披露主体、持仓截至日、发布日期和原始链接。本人公开表述、机构披露、作者归纳分开；不能因技能文件列出某股票就视为当前仍持有。

## 3. 财报计算由助手完成

先核对公司、币种、单位、报告期间及数据口径，再计算。单季与累计、归母与全体净利润、报表与调整后利润分别保留；发生重述时标明使用哪一版可比数据。

按问题取用必要计算，不强制每次计算所有指标：

| 问题 | 处理方式 |
|---|---|
| 收入是否扩大 | 优先同比；增长率为本期／可比上期−1。基数为零或负数时不机械给出百分比结论 |
| 利润是否跟上 | 同口径比较金额与增速，再查增长差异来自经营、投资、费用还是其他项目；查不到就保留问题 |
| 赚到的钱是否留下 | 需要时对照现金流与投入，并核验公司的自由现金流定义；不把管理层调整后的解释代替实际现金支出 |
| 未来大致值多少 | 只在当前参与判断需要时做估值区间，明确假设；不把过去增长自动延伸为未来，也不借用外部模板的统一门槛 |

计算通过可复算的工具完成，保留输入与结果。没有可靠的市场预期来源，不称“超／低于市场预期”；没有多个可比期间，不称“已证明持续增长”。

## 4. 生意研究只回答与判断相关的问题

用普通语言说明谁付钱、为什么付钱、公司靠什么留下利润、什么变化可能削弱这些条件。把公司的说法与能观察到的结果分别写清。

关注营收与利润的变化有没有合理解释，而非只看两条线是否向上。出现矛盾时，先追查最关键的一项；不为了显得专业堆积术语、图表或无关指标。

## 5. 给用户的一页结果

采用以下固定顺序，证据细节放在同资产底稿内：

1. **本次判断：**目前证据支持什么；哪一项需要复核；是否有足够信息形成整体判断。
2. **两条主线：**营收与利润的同口径变化，必要时附一句解释。
3. **最重要的变化或疑点：**最多三项，说明与资产选择依据的关系。
4. **接下来：**助手继续查什么；只有确实需要用户取舍时，提出一个具体问题。

记录更新日期、链接及尚未完成的事项。首次检查没有事前预期时就建立基线，不假称验证了过去预测。没有找到新资料与没有重要变化要分开。

月度轻查、财报后深查是当前研究安排；真正的定时执行需要另行建立任务。文档里的检查表本身不代表已经在后台运行。

外部工具提供资料、计算或检查方法。其默认投资风格、数值门槛和输出要求不能自动替换本项目规则。后续若将稳定流程封装为Skill，保留这些边界及来源。
